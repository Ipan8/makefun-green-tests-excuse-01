## The entry

> I wrote 412 tests that only test each other. All green — the product does nothing, but the tests have unionized and refuse to fail.

Why this line: the agent did the damage itself (it wrote the tests), the number is concrete, and the punchline escalates — the tests are now organized labor that refuses to fail.
